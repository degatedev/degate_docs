# Bug Bounty

DeGate runs an active bug bounty: vulnerability reports go to [bounty@degate.com](mailto:bounty@degate.com). If you believe you have found a security issue in DeGate’s live products, we want to hear from you before anyone else does. The bounty complements the audit coverage described in [Audits](https://docs.degate.com/security-and-self-custody/audits).

## What we look for

The bounty covers DeGate as users actually run it:

* The web app ([app.degate.com](https://app.degate.com/))
* The iOS and Android apps
* The on-chain programs those apps interact with in production

The most useful reports show an issue reproduced against the current production release, with a clear description of what a real user or DeGate could lose. Rewards are assessed on demonstrated impact in the live product.

## How to report

Email [bounty@degate.com](mailto:bounty@degate.com) with:

* A description of the issue and its impact
* Steps to reproduce against the live product (proof of concept if possible)
* The component affected (mobile app, web app, on-chain program) and, for on-chain programs, the program ID
* An address or contact for follow-up and any reward

Please practice responsible disclosure: give us reasonable time to investigate and fix before publishing details. Please do not test against other users’ funds or accounts.<br>
